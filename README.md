# xAI-decision-analysis

In this project, I build a machine learning model to predict student performance using a Kaggle dataset. I use SHAP to understand how different features influence the model’s predictions and to make the results easier to interpret.

## Key Insight

I find that factors like test preparation and access to resources have the strongest impact on predictions. At the same time, features such as gender and parental education also influence the model, which highlights bias and the need for careful interpretation.

## Takeaway

This project shows how explainable AI can help make model decisions more transparent. I also show that these explanations should be used with caution, as they reflect patterns in the data and not true cause-and-effect relationships.
